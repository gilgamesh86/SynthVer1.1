# Synth Ver1.1

I tried making a synthesizer out of my Casio SA-77 (gutted it and didn't want throw it away)


## Features

* Monophonic with 44 keys 
* Two selectable wavetables (Sine and Saw)
* Controllable ADSR envelope
* Up to 8 voice unison with exponential detune spread
* OLED display for user interface
* Rotary encoder based tweaking (no inaccurate potentiometers)


## Hardware details

MCU: STM32G431

DAC: PCM5100A ([WeAct Module](https://robu.in/product/weact-studio-i2s-speaker-module-pcm5100a))

OLED: SH1106 1.3 inch (I2C)

Casio model: SA-77
